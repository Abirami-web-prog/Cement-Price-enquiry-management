# 🏗️ Cement Price Enquiry Management System

A web-based application designed to manage cement price enquiries and provide an organized way to handle customer requests and cement-related information.

---

## 🎯 Project Objective

The main objective of this project is to simplify the process of handling cement price enquiries by providing a digital platform for managing customer requests and responding to enquiries efficiently.

---

## ✨ Features

- 📋 Cement Price Enquiry Management
- 👥 Customer Enquiry Handling
- 💰 Cement Price Information
- 🔄 Frontend and Backend Integration
- 📱 User-Friendly Interface
- ⚡ Efficient Enquiry Management

🚀 Getting Started

Prerequisites

Make sure you have the following installed:

Node.js

npm

MySQL

Git



---

📥 Clone the Repository

git clone https://github.com/Abirami-web-prog/Cement-Price-enquiry-management.git

Open the project:

cd Cement-Price-enquiry-management


---

💻 Frontend Setup

Go to the frontend directory:

cd Frontend

Install the dependencies:

npm install

Start the frontend:

npm run dev


---

⚙️ Backend Setup

Open a new terminal and go to the backend directory:

cd backend

Install the dependencies:

npm install

Start the backend using the command configured in the backend package.json.


---

🗄️ Database

This project uses MySQL for storing application data.

The backend communicates with the database to manage cement price enquiry-related information.

Database credentials should be stored securely using environment variables.


---

🔐 Environment Variables

If the backend requires environment variables, create a .env file inside the backend directory.

Example:

PORT=5000
DB_HOST=localhost
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=your_database

Replace the values with your local database configuration.

> ⚠️ Never upload your actual .env file or database passwords to GitHub.
